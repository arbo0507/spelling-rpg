# 🛡️ Spelling RPG (拼字大冒險)

這是一個結合復古 RPG 風格與英文學習的網頁遊戲。玩家扮演一位勇者，必須透過正確拼寫英文單字來發動攻擊，擊敗眼前的怪物！

## 🎮 立即遊玩 (Play Now)
👉 **[點擊這裡開始遊戲](https://arbo0507.github.io/spelling-rpg/)**

## ✨ 遊戲特色 (Features)

*   **⚔️ 戰鬥學習**：將枯燥的背單字過程轉化為緊張刺激的回合制戰鬥。
*   **🔊 語音朗讀**：內建語音合成 (Web Speech API)，聽音辨字，訓練聽力。
*   **🎨 復古像素風**：經典的 RPG 介面設計，包含血條 (HP)、經驗值 (EXP) 和動態戰鬥訊息。
*   **📈 等級系統**：隨著答對次數增加，勇者會升級並提升攻擊力。
*   **📱 響應式設計**：支援電腦與手機遊玩。

## 🕹️ 如何遊玩 (How to Play)

1.  **聆聽單字**：點擊喇叭圖示 🔊 聽取單字發音。
2.  **輸入拼寫**：在輸入框中打出正確的英文單字。
3.  **發動攻擊**：
    *   ✅ **答對**：勇者攻擊怪物，獲得經驗值。
    *   ❌ **答錯**：攻擊失敗，怪物會反擊扣除勇者 HP。
4.  **勝利條件**：將怪物的 HP 歸零即可獲勝！

## 🛠️ 使用技術 (Tech Stack)

*   **HTML5**: 建構遊戲結構與語意。
*   **CSS3**: 處理遊戲視覺風格、動畫效果與響應式佈局。
*   **JavaScript (Vanilla JS)**: 
    *   遊戲核心邏輯 (戰鬥計算、狀態管理)。
    *   DOM 操作與事件監聽。
    *   Web Speech API (文字轉語音)。
